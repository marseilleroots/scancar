Politique de Confidentialité - ScanCar

Dernière mise à jour: 17 mai 2026

1. Introduction

ScanCar ("nous", "notre" ou "nos") exploite l'application ScanCar.

Cette page vous informe de nos politiques concernant la collecte, l'utilisation et la divulgation de données personnelles lorsque vous utilisez notre application mobile.

2. Collecte de Données

2.1 Plaques d'immatriculation

Vous fournissez volontairement les plaques d'immatriculation que vous scannez. Ces données sont envoyées à notre partenaire API (Carvertical) pour générer un rapport.

2.2 Informations de Localisation

Pour la fonctionnalité de scan de plaque, nous pouvons accéder à votre appareil photo mais ne collectons pas votre position géographique.

2.3 Données d'Application

Nous collectons automatiquement:

  • Type et version de votre appareil
  • Version du système d'exploitation
  • Rapports d'erreurs et performances
  • Journaux d'utilisation de l'application

2.4 Données de Publicité

Les annonces affichées dans l'application peuvent collecter des identifiants d'appareil pour personnaliser le contenu publicitaire.

3. Utilisation des Données

Les données que nous collectons sont utilisées pour:

  • Générer des rapports de véhicules complets via Carvertical API
  • Améliorer les performances et la stabilité de l'application
  • Afficher des publicités pertinentes
  • Analyser comment les utilisateurs utilisent l'application

4. Partage de Données

Vos données de plaques d'immatriculation sont partagées avec:

  • Carvertical API - pour générer les rapports de véhicules
  • Google AdMob - pour afficher et optimiser les publicités

Nous ne vendons pas vos données personnelles à des tiers.

5. Sécurité des Données

Nous utilisons des connexions HTTPS chiffrées pour transmettre les données. Cependant, aucune méthode de transmission sur Internet n'est 100% sécurisée.

6. Rétention des Données

Les plaques d'immatriculation que vous scannez ne sont pas stockées sur nos serveurs après la génération du rapport. Les données analytiques sont conservées pendant 12 mois.

7. Vos Droits

Vous avez le droit de:

  • Accéder aux données que nous avons collectées sur vous
  • Demander la suppression de vos données
  • Retirer votre consentement à tout moment

Contactez-nous à: contact@scancar.app

8. Enfants

Notre application n'est pas destinée à des enfants de moins de 13 ans. Nous ne collectons pas sciemment de données provenant d'enfants de moins de 13 ans.

9. Modifications de la Politique

Nous pouvons mettre à jour cette politique de confidentialité de temps à autre. Nous vous notifierons de tout changement en mettant à jour la date de "Dernière mise à jour".

10. Contactez-nous

Si vous avez des questions concernant cette politique de confidentialité, veuillez nous contacter à:

Email: contact@scancar.app
