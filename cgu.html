2. Description du service

ScanCar est une application web gratuite qui permet de scanner ou saisir une plaque d'immatriculation européenne afin d'obtenir un rapport véhicule incluant :

  • Caractéristiques techniques officielles (SIV)
  • Historique véhicule (via CarVertical et Histovec)
  • Estimation de valeur marché
  • Score d'achat indicatif
  • Informations écologiques (Crit'Air, ZFE, CO₂)
